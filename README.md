# Resoom Home Assistant Custom Component

Resoom 전열교환기를 Home Assistant에서 조회·제어하는 비공식 통합입니다. Resoom 클라우드 계정과 인터넷 연결이 필요합니다.

버전 **0.1.0** · 검증 환경 **Home Assistant 2026.10.1 / Python 3.14**.

## 설치

1. 이 저장소의 `custom_components/resoom` 폴더를 Home Assistant 설정 디렉터리의 `custom_components/resoom`으로 복사합니다.
2. Home Assistant를 재시작합니다.
3. **설정 → 기기 및 서비스 → 통합 구성요소 추가 → Resoom**에서 계정 이메일과 비밀번호를 입력합니다.

HACS 저장소 메타데이터는 `hacs.json`에 포함되어 있습니다. 비공개 저장소의 설치·접근 가능 여부는 사용하는 도구의 지원 범위를 확인하세요. 수동 설치는 위 절차를 사용합니다.

## 기능

- 전원 켜기 / 대기 전환
- 즉시 운전 풍량 설정 1~10단
- 양압·정압·음압 설정
- 자동 긴급차단, 급기 팬, 배기 팬, 수면, 바이패스 설정
- 보고 풍량·운전 모드·필터 및 전열소자 잔여량
- 한국어·영어, 기기별 12개 엔티티, 30초 상태 갱신, 계정 재인증

**풍량·압력·부가기능 설정을 변경하면 즉시 운전이 시작되거나 기존 스마트·예약 운전이 전환될 수 있습니다.** 설정 풍량과 실제 보고 풍량은 구분해 표시합니다. 자동 긴급차단 설정은 즉시 긴급 정지 명령이 아닙니다.

명령은 저장 설정 또는 보고 상태를 후속 조회해 확인합니다. 확인 실패·timeout 후 POST를 자동 재전송하지 않습니다. 오류 시 앱과 실제 기기 상태를 확인하세요.

이 저장소에는 배포용 통합 파일과 설치 메타데이터만 포함합니다. Resoom 또는 Home Assistant 공식 통합이 아닙니다.
